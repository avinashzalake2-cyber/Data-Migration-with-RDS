# Data-Migration-with-RDS
This project demonstrates how to migrate data from an on-premises database to Amazon RDS (Relational Database Service). The goal is to ensure secure, efficient, and minimal-downtime transfer of structured data to a managed AWS database instance. USE TechniTechnologies Used  1.Amazon RDS,2.AWS DMS (Database Migration Service)3.AWS DMS,3.EC2,4.Shell
